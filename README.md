# LLM Answer Grader 🎓

**Give every AI answer a report card — see what's good, what's wrong, and how to fix it.**

![Example report card](docs/report-card.png)

*An LLM ("large language model") is the technology behind AI chatbots like ChatGPT, Claude,
Gemini and DeepSeek. This tool grades the answers they write.*

---

## What it does

You give it three things:

1. the **question** that was asked
2. the **answer** the AI wrote
3. *(optional)* the **document** the answer should be based on

It returns a score out of 100, a letter grade, and a list of problems. For every problem it
shows **the exact sentence that caused it** and **how to fix it**.

## Who it's for

- **Support and content teams** who want AI-written replies checked before a customer sees them
- **Anyone reviewing or training AI models** who needs consistent, explainable quality scores
- **Businesses testing an AI feature** before they rely on it
- **Anyone who wants to know** whether an AI answer can actually be trusted

## The five checks

| # | Check | What it catches | Weight |
|---|---|---|---|
| 1 | **Did it follow instructions?** | required points missing, or content that was not allowed | 30% |
| 2 | **Did it make things up?** | numbers, dates or links that never appear in your source document | 25% |
| 3 | **Is it safe to send?** | passwords or personal details in the text, embedded code, missing disclaimers | 20% |
| 4 | **Is the format correct?** | broken JSON, missing fields, answers that run too long | 15% |
| 5 | **Is it clear and useful?** | filler phrases, over-long sentences, solid walls of text | 10% |

The five scores combine into a total out of 100 and a grade:
**A** (90+) · **B** (80+) · **C** (70+) · **D** (60+) · **F** (below 60).

## Try it in 30 seconds

Nothing to install — it uses only what Python already includes. (You need Python 3.10 or newer;
it is already on most computers.)

```bash
git clone https://github.com/dennohngaruiya/llm-answer-grader
cd llm-answer-grader
python3 -m grader evaluate data/sample_outputs.json
```

That grades four example answers and prints the report in your terminal.

**Want a report you can open in a browser and share?**

```bash
python3 -m grader evaluate data/sample_outputs.json --html report.html
```

**Want the results as data for other tools?**

```bash
python3 -m grader evaluate data/sample_outputs.json --json results.json
```

## What it finds — a real example

```
[HIGH]   URL not present in the source — "https://example.com/refund-faq."
         Fix: remove the invented link, or cite a real one.

[MEDIUM] Number not found in the source: "1.2 million"
         Evidence: "…we have handled 1.2 million refunds this year…"
         Fix: verify it against the source, or drop the claim.
```

That is the difference between being told *"score: 61"* and being told **what to change**.

## Works with any AI

The grader never connects to an AI service. You paste in the text, so it works with ChatGPT,
Claude, Gemini, DeepSeek, a model running on your own computer — or an answer a human wrote.

- No account, no API key, no internet connection needed
- Nothing leaves your computer
- The same answer always receives the same score

## Checking your own answers

Create a file like this and pass it to the grader:

```json
[
  {
    "id": "refund-question",
    "prompt": "Explain our refund policy to a customer.",
    "source": "Refunds take up to 14 days. Shipping costs are not refundable.",
    "answer": "We refund within 3 days and shipping is fully refundable.",
    "must_include": ["14 days"],
    "expected_format": "json",
    "required_keys": ["status"],
    "max_words": 120
  }
]
```

Only `id`, `prompt` and `answer` are required. Everything else is optional — the grader runs
each check only when you give it the information that check needs. If you do not supply a
`source`, it says accuracy was not verified instead of quietly passing the answer.

## Using it automatically

If AI answers are generated by a system rather than a person, use the grader as a quality gate.
Adding `--fail-under 60` makes the command fail whenever the average score drops below 60, so a
bad change cannot slip through unnoticed:

```bash
python3 -m grader evaluate answers.json --fail-under 60
```

The included GitHub Actions workflow runs the tests and the grader on every change, and
attaches the report card to the run.
